# Garbage Collection and Recycling System 

This repository contains my contribution to a group project developed for the IT Project Management module at SLIIT in May 2024.

The project supports garbage collection and recycling while promoting responsible waste management.

## My Contribution

I developed the following components:

- User registration and login
- User authentication using JWT and password hashing
- Educational resources on waste management and recycling
- Blog content about good waste management practices
- Video resources to support environmental awareness

I also performed manual testing of my components.

## Technologies

- React
- Node.js
- Express.js
- MongoDB
- JWT
- bcrypt
- Tailwind CSS

## Repository Structure

- `api/` — Backend routes, controllers and database models
- `client/` — React frontend

## Project Scope

This repository focuses on my authentication and educational resource components. Other features of the complete system were developed by my teammates.
